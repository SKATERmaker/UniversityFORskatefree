# University

Mapa da comunidade para o **Skate Free**, com um distrito universitário completo para explorar: praças, escadarias, corrimãos e bowls.

## Informações

- **Nome no jogo:** University District
- **Categoria:** Mundo Aberto
- **Formato:** `.skt`
- **Tamanho:** 63,8 MB
- **Versão:** 1.0

## Download

Baixe o arquivo **University.skt** na seção [Releases](https://github.com/SKATERmaker/UniversityFORskatefree/releases) deste repositório.

## Como adicionar ao jogo

### Por link

1. Na release, copie o endereço de download do arquivo **University.skt**.
2. Abra o **Skate Free**.
3. Selecione **Adicionar por Link**.
4. Cole o endereço e confirme o download.

### Por arquivo

1. Baixe o **University.skt** no seu dispositivo.
2. Abra a opção de importar mapas no **Skate Free**.
3. Selecione o arquivo baixado.

**Mantenha a extensão `.skt`. Não é necessário extrair o arquivo.**
